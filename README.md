# Employee Management Backoffice (Angular)

## 🛠️ Tech Stack
- Angular v13
- Bootstrap v4 & SCSS
- SweetAlert2 (Notification)
- Ng-Select (Searchable Dropdown)

## 🔑 Kredensial Login
- **Username**: `admin`
- **Password**: `admin`

## 🚀 Cara Menjalankan Aplikasi

1. **Instal Dependensi**:
   ```bash
   npm install
   ```

2. **Jalankan Aplikasi**:
   ```bash
   npm start
   ```

3. **Buka Browser**:
   Buka **[http://localhost:4200](http://localhost:4200)**

## ✨ Fitur yang Diimplementasikan
1. **Login Page**
2. **Employee List Page**:
   - List karyawan dengan sorting, search dan filter
3. **Add Employee Page**:
   - Form validasi karyawan baru
4. **Employee Detail Page**:
   - Detail informasi karyawan
